# City directory

Source: GeoNames `cities15000.zip` and `admin1CodesASCII.txt`, downloaded 2026-11-25 from https://download.geonames.org/export/dump/.

34,246 populated places: cities with population above 15,000 and capitals. This is not every village, hospital, or historical place name. Coordinates are city centres, not an exact birth address. Manual location entry remains available. Region names help distinguish places sharing a name.

The local extract includes GeoNames ID, name, ASCII name, country code, first-order region name, latitude, longitude, IANA timezone and population. It omits alternate-name lists. Search and selection stay in the browser; no search query or case data is sent to GeoNames. The static directory is downloaded from this app on first focus. Normal timezone rules are resolved against the birth date by the existing civil-time engine; directory timezones are modern identifiers and may need manual correction for historical boundary changes. Altitude is not provided or inferred.
